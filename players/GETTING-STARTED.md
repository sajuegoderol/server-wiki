# Primeros pasos

## Antes de ingresar

La versión del cliente, el método de conexión y cualquier recurso adicional deben confirmarse con la publicación oficial vigente. No descargues paquetes desde enlaces no autorizados.

## Recorrido previsto

1. Consultar el estado y la versión admitida.
2. Preparar el cliente compatible.
3. Conectarse mediante la dirección oficial.
4. Completar el proceso de cuenta.
5. Crear o seleccionar un personaje.
6. Revisar las reglas y guías básicas de rol.

## Datos pendientes
