# Fundamentos de rol

> **Estado:** base editorial; requiere enlazar el reglamento oficial.

## Interpretación

El objetivo es representar un personaje coherente dentro de un entorno compartido. Las acciones deben considerar el contexto, las capacidades del personaje y las consecuencias narrativas.

## Separación de información

- **Dentro del personaje:** información obtenida por el personaje durante el rol.
- **Fuera del personaje:** información del jugador, interfaces o canales externos.

No debe utilizarse información externa para obtener ventajas dentro del rol.

## Acciones narrativas

Los comandos y formatos exactos para describir acciones se incorporarán cuando el sistema de chat vigente haya sido auditado. Hasta entonces, esta página no reemplaza las reglas oficiales.

## Convivencia

- respetar a las demás personas;
- priorizar escenas comprensibles y recíprocas;
- utilizar los canales adecuados para dudas o reportes;
- seguir las decisiones del equipo mediante los procesos de revisión disponibles.
