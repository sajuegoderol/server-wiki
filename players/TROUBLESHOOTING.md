# Resolución de problemas

> **Estado:** pendiente de validar mensajes y rutas de soporte.

## Antes de solicitar ayuda

1. Confirmar que utilizás la versión del cliente admitida.
2. Verificar el estado oficial del servicio.
3. Reiniciar el cliente y volver a intentar.
4. Registrar el mensaje exacto y el momento aproximado del problema.
5. Ocultar contraseñas, direcciones privadas y datos personales de cualquier captura.

## Información útil para soporte

- problema observado;
- resultado esperado;
- pasos para reproducirlo;
- fecha y hora aproximadas;
- versión del cliente;
- captura o video sin datos sensibles.

## Problemas que se documentarán

- conexión y descarga de recursos;
- ingreso y recuperación de cuenta;
- carga o selección de personaje;
- cierres del cliente;
- interfaces o textos faltantes;
- errores después de una actualización.
