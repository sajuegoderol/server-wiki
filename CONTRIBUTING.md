# Contribuir a la wiki

## Antes de escribir

1. Identificar el público de la página.
2. Confirmar el funcionamiento real del sistema.
3. Localizar evidencia en código, pruebas, release o decisión oficial.
4. Revisar si ya existe una página relacionada.
5. Evitar copiar información temporal de Discord como fuente definitiva.

## Flujo

1. Actualizar `master`.
2. Crear una rama `docs/<tema>`.
3. Utilizar una plantilla de `templates/`.
4. Revisar enlaces, privacidad y español latinoamericano.
5. Abrir un Pull Request hacia `master`.

## Evidencia aceptable

- comportamiento comprobado dentro del servidor;
- código vigente de `server-engine`;
- documentación de una release publicada;
- decisión explícita del equipo responsable;
- capturas o registros sin datos sensibles.

## No publicar

- credenciales o configuraciones reales;
- información personal de jugadores o integrantes;
- herramientas internas de moderación que faciliten abusos;
- consultas, rutas o infraestructura privada;
- fechas, comandos o sistemas no confirmados.

## Cambios de comportamiento

Cuando una actualización modifica una guía:

1. actualizar primero la página permanente;
2. relacionar el cambio con su release o Pull Request;
3. indicar requisitos o incompatibilidades;
4. conservar notas históricas únicamente cuando ayuden al usuario.
