# Documentación del equipo

Esta sección contendrá procedimientos públicos o compartibles para moderación, soporte, eventos y mantenimiento editorial.

## Límites

No se almacenarán:

- credenciales;
- permisos internos detallados que faciliten abuso;
- datos personales o expedientes privados;
- técnicas de detección sensibles;
- infraestructura operativa.

La documentación confidencial debe permanecer en una plataforma con acceso controlado, no en este repositorio público.

## Contenido previsto

- atención y escalamiento de consultas;
- mantenimiento de guías;
- comunicación de incidencias;
- criterios de actualización de la wiki;
- coordinación con releases y devblogs.
