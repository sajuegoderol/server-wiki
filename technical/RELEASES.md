# Versiones y releases

## Conceptos

- **Versión:** identidad funcional visible para la comunidad.
- **Build:** compilación asociada a un commit exacto.
- **Tag:** referencia inmutable utilizada por una release.
- **Release:** versión aprobada con notas y artefactos.

## Estado histórico conocido

| Versión | Estado |
|---|---|
| `v0.0.1` | Histórica publicada |
| `v0.0.2` | Última histórica publicada localizada |
| `v0.0.3`–`v0.0.5` | Sin evidencia suficiente |
| `v0.0.6b` | Objetivo en preparación; no publicada |

## Fuentes

- Estado técnico: `server-engine`.
- Paquetes e instrucciones: `server-release`.
- Explicación permanente: esta wiki.

Nunca debe interpretarse una versión “en preparación” como disponible para jugadores.
