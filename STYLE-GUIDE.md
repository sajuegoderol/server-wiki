# Guía de estilo

## Idioma

La wiki utiliza español latinoamericano. Se prefieren expresiones claras y neutrales, evitando traducciones literales innecesarias.

## Voz y tono

- Explicar directamente qué puede hacer el usuario.
- Utilizar segunda persona cuando una instrucción lo requiera.
- Distinguir obligación, recomendación y ejemplo.
- Evitar promesas sobre contenido todavía no publicado.

## Términos

| Preferido | Evitar |
|---|---|
| iniciar sesión | loguearse, logear |
| personaje | char, PJ cuando no esté definido |
| jugador | user |
| servidor | server en texto comunitario |
| equipo administrativo | staff cuando no sea un nombre oficial |

Los nombres técnicos, comandos y rutas se mantienen exactamente como funcionan.

## Formato

- Un solo título principal por archivo.
- Encabezados breves y descriptivos.
- Pasos numerados para procedimientos.
- Tablas únicamente cuando faciliten comparar datos.
- Bloques de código para comandos, rutas o ejemplos literales.
- Enlaces relativos entre páginas del repositorio.

## Estados documentales

- **Validada:** comportamiento comprobado.
- **Pendiente de validación:** estructura disponible, contenido incompleto.
- **Obsoleta:** no debe utilizarse y apunta a su reemplazo.

## Accesibilidad

- Describir el propósito de imágenes y capturas.
- No depender exclusivamente del color.
- Explicar abreviaturas la primera vez que aparecen.
- Mantener instrucciones útiles sin necesidad de observar una imagen.
