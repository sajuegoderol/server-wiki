## Estado

La estructura base está disponible, pero varias páginas todavía requieren validar su contenido contra `server-engine`. Una página marcada como **pendiente de validación** no debe utilizarse como norma definitiva.

## Ecosistema oficial

| Repositorio o canal | Función |
|---|---|
| `server-engine` | Código fuente, desarrollo y pruebas |
| `server-release` | Versiones, instalación y rollback |
| `server-wiki` | Documentación permanente |
| Foro | Devblogs, anuncios extensos y discusión |
| PCU | Información operativa para usuarios |
| Discord | Comunicación inmediata y enlaces |

## Principios

- Español latinoamericano claro y consistente.
- Información comprobada mediante código, pruebas o decisiones oficiales.
- Separación entre instrucciones para jugadores y detalles internos.
- Sin credenciales, datos personales, infraestructura privada ni procedimientos sensibles.
- Historial corregible: una guía se actualiza cuando cambia el sistema, sin reescribir releases antiguas.
